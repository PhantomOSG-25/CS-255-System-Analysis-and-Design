# Selected original coursework

This folder preserves sanitized copies of the original CS 255 work for provenance. The files are not presented as current production specifications.

## Sanitization applied

- Removed document creator and last-editor metadata
- Removed custom properties and Word revision-session identifiers
- Removed embedded local template references
- Removed the student email address from the model-application paper
- Excluded Getty Images/iStock persona photographs
- Preserved the authored academic content and diagrams

## Relationship to the portfolio enhancement

The files in this folder show the original analysis process. The repository-level case study, requirements catalog, traceability matrix, architecture decisions, security review, and corrected diagrams were created later to demonstrate how the work would be prepared for professional review.

Known notation and wording issues in the original diagrams are intentionally not hidden. Corrected employer-facing versions are available in [`../../diagrams`](../../diagrams/README.md).
